# Sonam Portfolio

Complete editable HTML, CSS and JavaScript portfolio, including Intellicraft and BIBA project links.

## Open and preview
1. Extract this ZIP.
2. In VS Code, use File > Open Folder and choose Sonam-Portfolio.
3. Double-click index.html in Windows File Explorer to open it in a browser.
4. After editing, save and refresh your browser.

No npm installation or build step is required. This portfolio uses plain HTML, CSS and JavaScript; Angular and React are showcased skills, not the implementation framework.

## Edit
- index.html: text, sections, project links, skills, experience and contact details. Delete the relevant section markup to remove a section, and remove its navigation link too.
- styles.css: colors, fonts, layout, spacing and mobile styles.
- script.js: mobile menu and footer year.
- Sonam-Kumari-Resume.pdf: replace this file with your updated resume using the same filename.

Fonts load from Google Fonts; fallback fonts are included.

## Hosting
index.html is already at the project root. This folder is ready for static hosting, including GitHub Pages. No dist folder or ChatGPT hosting configuration is needed.
Local edits do not automatically change the previously hosted ChatGPT Site.
